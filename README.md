# WPF Calculator

## Description

WPF Calculator is a simple and elegant desktop calculator application built using Windows Presentation Foundation (WPF) and C#. The application provides basic arithmetic functions such as addition, subtraction, multiplication, and division. It also includes a user-friendly interface designed with modern WPF elements.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division.
- Clear (C) and delete (backspace) buttons for easy input correction.
- Responsive UI with modern WPF controls.
- Supports both integer and floating-point numbers.

## Technologies Used

- **C#**: Primary programming language for backend logic.
- **WPF (Windows Presentation Foundation)**: Framework for building the UI.
- **XAML**: Used to define the layout and design of the UI.

## Requirements

To run this application, you'll need the following:

- **.NET Framework** (version 4.8 or higher)
- **Visual Studio** (or any compatible IDE for C# development)
- A Windows operating system (since WPF is primarily designed for Windows).

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Iulia-plesu/WPF_Calculator.git
```

### 2. Open the Project

Open the solution (`.sln` file) in **Visual Studio**.

### 3. Build and Run the Project

After opening the project in Visual Studio:

- Press `Ctrl + Shift + B` to build the solution.
- Press `F5` or click on the "Start" button to run the application.

The calculator should now open, and you can start using it.

## Usage

- Enter numbers using the on-screen buttons.
- Click on arithmetic operators (like `+`, `-`, `*`, `/`) to perform calculations.
- Use the `C` button to clear the display.
- Use the backspace button to delete the last entered digit.
